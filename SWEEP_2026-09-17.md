# Sweep 2026-09-17 — Netherlands + Germany

## What ran, and the honest source limitation

| Source | Yield |
|---|---|
| `harvest_sponsor_boards.py --country NL` | 913 boards / 848 companies → 25,916 live vacancies → 2,341 NL → 558 engineering titles → **160 new** |
| `harvest_sponsor_boards.py --country DE` | same 848 companies → 1,426 DE → 287 engineering → **87 new** → **zero real candidates** |
| `./hunt --locations Netherlands Germany --jobage 14 --pages 10` | 180 queries → pool 1,064 → **400 new** |
| **Total screened** | **560 bodies read** · 0 left unassessed |
| Verdicts | 430 EXCLUDE · 107 FLAG · 17 PASS · 6 UNREACHABLE |

**The source asymmetry, stated plainly:** `sponsor_ats_boards.json` is the **Dutch** IND
recognised-sponsor register. Running it with `--country DE` does not search German employers — it
filters the same Dutch sponsors' German vacancies, which skew to sales, consulting and support
rather than core engineering. That is why DE returned nothing usable. **Germany has no equivalent
register, so German coverage rests on LinkedIn alone.** Worth remembering before concluding "there
is nothing in Germany".

**Process error to not repeat:** the first pass filtered survivors at `python_weight >= 3`, which
cut ~100 entries unseen. That threshold was mine, not the tool's, and it is unreliable — the two
Adyen reqs score **py=1** despite one being *titled* "Python Software Engineer". Rank by
`python_core` and absence of core rivals instead, never by the raw count.
